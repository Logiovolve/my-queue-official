LINE順番呼び出しシステム 初期設定ガイド

LINE Developers・Messaging API・LIFF設定の完全マニュアル

STEP 1 LINE Official Account（公式アカウント）の作成

  1. LINE Official Account Manager（manager.line.biz）にアクセスします。
  2. 「アカウント作成」をクリックし、店舗名・連絡先・業界カテゴリを入力して登録を完了します。
  3. 管理画面トップの「応答設定」から、応答モードを「チャット」または「Bot」に設定します。

STEP 2 LINE Developers プロバイダー＆チャネルの作成

  1. LINE Developers Console（developers.line.biz）へログインします。
  2. 「プロバイダーを作成」ボタンを押して、店舗名や組織名（例: 「マイカフェ」）を入力します。
  3. 「新規チャネル作成」から Messaging API を選択します。
  4. チャネル名・説明文・アプリ用画像を登録し、利用規約に同意して「作成」をクリックします。

STEP 3 チャネルアクセストークン（長期）の発行

  1. 作成したMessaging APIチャネルの設定画面を開きます。
  2. 「Messaging API設定」タブを選択し、ページ最下部までスクロールします。
  3. 「チャネルアクセストークン（長期）」の横にある「発行」ボタンをクリックします。
  4. 生成された長い文字列（トークン）をコピーし、my-queue管理画面に入力します。

STEP 4 LIFF（LINE Front-end Framework）アプリの登録

  1. LINE Developers画面で「LIFF」タブを開き、「追加」ボタンを押します。
  2. LIFFアプリ名（例: 整理券発券画面）を入力します。
  3. サイズは「Full」または「Tall」を選択します。
  4. エンドポイントURLにmy-queueから提供された発券画面URLを入力し、保存します。
  5. 発行された「LIFF ID（例: 2001234567-AbCdEfGh）」をコピーして設定に貼り付けます。

STEP 5 動作確認と店舗用QRコードの印刷

  1. my-queue管理パネルの「店舗用QRコードを表示・印刷」ボタンを押します。
  2. スマートフォンで表示されたQRコードを読み取り、LINEで整理券が正常に発行されるかテストします。
  3. 管理画面で「次の方を呼び出す」を押し、LINEに通知メッセージが届くことを確認します。
  4. 確認完了後、印刷用ボタンからQRコードPOPを出力して店頭に掲示してください。
設定に不安がある場合

設定作業中にエラーが発生する場合や、手順が不明な場合は「初期設定おまかせ代行（+2,000円）」をご利用いただくことで、スタッフが最短15分で全ての設定を代行いたします。
